# 📊 Estadísticas con Kotlin

## 📌 Descripción del proyecto

Este proyecto consiste en desarrollar una aplicación de consola utilizando **Kotlin**, que permite trabajar con una lista de 100 números y realizar diferentes cálculos estadísticos.

El programa ofrece un menú interactivo desde el que el usuario puede generar números aleatorios, introducirlos manualmente y consultar diferentes estadísticas.

## 🚀 Funcionalidades

El programa incluye las siguientes opciones:

1. **Generar 100 números aleatorios:** crea 100 números entre 1 y 100.
2. **Introducir 100 números manualmente:** permite introducir los números por teclado.
3. **Mostrar números:** muestra todos los números almacenados.
4. **Calcular media:** obtiene la media de los 100 números.
5. **Calcular moda:** muestra el número o números que más se repiten.
6. **Calcular desviación típica:** calcula cuánto se alejan los valores de la media.
7. **Calcular todas las estadísticas:** muestra todos los resultados juntos.
0. **Salir:** finaliza el programa.

## 🛠️ Tecnologías utilizadas

- Kotlin
- IntelliJ IDEA
- Aplicación de consola

## 📂 Estructura del proyecto

El proyecto está organizado en tres archivos principales:

| Archivo | Descripción |
|---|---|
| `Main.kt` | Inicia la ejecución del programa. |
| `Menu.kt` | Contiene el menú y controla las opciones del usuario. |
| `Estadisticas.kt` | Contiene las funciones para calcular la media, moda y desviación típica. |

## ▶️ Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir el proyecto con IntelliJ IDEA.
